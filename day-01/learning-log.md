\# Practical Learning Lab



\## Day 1 — Git \& GitHub



\### What I learned

\- Git is a version control system.

\- Git tracks changes made to files.

\- GitHub stores repositories online.

\- A repository contains project files and their history.

\- A commit is a snapshot of changes.

\- Push uploads local commits to GitHub.



\### Commands I used

\- `git clone` — copies a remote repository to my PC.

\- `ls` — lists files and folders.

\- `cd` — changes the current directory.

\- `mkdir` — creates a new folder.

\- `touch` — creates a file.
